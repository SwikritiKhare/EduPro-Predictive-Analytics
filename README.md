# 🎓 EduPro Predictive Analytics Dashboard

## 📌 Project Overview

The EduPro Predictive Analytics Dashboard is a Machine Learning and Business Intelligence project developed to forecast course demand and revenue for an online learning platform.

This project helps EduPro make data-driven decisions regarding:
- Course launches
- Pricing strategies
- Instructor onboarding
- Revenue planning
- Demand forecasting

The dashboard transforms historical educational data into predictive business intelligence using Machine Learning and interactive visual analytics.

---

# 🚀 Objectives

The main objectives of this project are:

✅ Predict course enrollment demand  
✅ Forecast revenue generation  
✅ Analyze instructor impact on enrollments  
✅ Identify important business drivers  
✅ Build an interactive Streamlit dashboard

# 📌 Key Business Insights

- High-rated courses generate better enrollments.
- Experienced instructors improve course demand.
- Mid-priced courses perform better than expensive courses.
- Teacher ratings strongly influence student enrollments.
- Longer duration courses contribute higher revenue.
